Install

Windows

  • Unzip and run DustOps.exe.
  • The first time you host or join a LAN game, Windows asks about the firewall: tick Private networks and allow.
  • If SmartScreen says "Windows protected your PC": More info → Run anyway (the game isn't code-signed).

macOS

  • Unzip and drag Dust Ops.app to Applications.
  • Right-click it → Open → Open (needed once: the app isn't notarized).
  • Still refused? In Terminal: xattr -dr com.apple.quarantine "/Applications/Dust Ops.app"
  • Allow incoming connections when asked, so LAN games work.

Playing together

One player clicks Host LAN game, the others Join LAN game: the game shows up in the list, or type the host's IP. It uses UDP ports 7777 (game) and 7778 (discovery). Windows and Mac players can play together. The host picks bomb defusal or deathmatch in the lobby and can fill empty slots with bots.

Slow laptop? Main menu → Graphics: Lowest or Low.
